# Contract: SQL 分頁的畫面

使用者按「執行」或在編輯框按 Ctrl+Enter 之後，資料區、上方提示列和右下角提示依結果顯示如下。「多段」指這次切出來的段數大於 1。

| 情況 | 執行紀錄 | 表格 | 上方提示列 | 右下角提示 |
| --- | --- | --- | --- | --- |
| 一段，查詢 | 不顯示 | 查詢結果 | 「查詢結果 — M 筆」 | 「查詢結果 M 筆」 |
| 一段，寫入 | 不顯示 | 不顯示，資料區顯示 ✓ 和訊息 | 隱藏 | 該段的訊息，例如「執行成功 — 影響 2 筆資料」 |
| 一段，失敗 | 不顯示 | 資料區維持原樣 | 維持原樣 | 「SQL 錯誤：<資料庫錯誤訊息>」 |
| 多段，全部成功，有查詢 | 顯示在表格上方 | 最後一個查詢的結果 | 「第 N 段的查詢結果 — M 筆」 | 「K 段 SQL 全部執行成功」 |
| 多段，全部成功，沒有查詢 | 顯示 | 不顯示 | 隱藏 | 「K 段 SQL 全部執行成功」 |
| 多段，中途失敗 | 顯示，失敗那段標紅 | 有成功的查詢就顯示最後一個，否則不顯示 | 有表格時「第 N 段的查詢結果 — M 筆」，否則隱藏 | 「SQL 錯誤：第 N 段執行失敗：<資料庫錯誤訊息>」 |
| 只有註解 | 不顯示 | 維持原樣 | 維持原樣 | 「SQL 錯誤：沒有可執行的 SQL」 |

## 執行紀錄

每一段一行，由左到右：

1. ✓（綠色）或 ✕（紅色）
2. `#編號`，從 1 開始
3. SQL：去掉開頭的 `--` 註解行，換行和連續空白壓成一個空白，太長就用 `…` 截斷。滑鼠移上去顯示完整的原始文字
4. 結果：
   - 查詢：「M 筆」
   - 寫入：該段的訊息。MySQL 有新增 ID 時，後面加「（ID N）」
   - 失敗：資料庫的錯誤訊息，不加「第 N 段執行失敗：」

中途失敗時，紀錄最下面加一行灰色說明，依情況組合：

- 後面還有段落沒執行：「後面 K 段沒有執行。」
- 前面有成功的段落：「前面已成功的段落不會自動復原，除非它們在還沒 COMMIT 的交易裡。」

兩個條件都不成立時，不顯示說明。

SQL 文字和錯誤訊息一律照字面顯示，`<b>` 這類內容不會被當成 HTML（FR-015）。

## 執行後重新載入資料表

左側目前選著某張資料表時：

| 情況 | 行為 |
| --- | --- |
| 一段，寫入成功 | 800ms 後重新載入那張表，跟改版前一樣 |
| 有顯示查詢結果 | 不重新載入 |
| 多段，有顯示執行紀錄 | 待確認，見 research.md R8。建議不重新載入，避免執行紀錄被蓋掉 |
